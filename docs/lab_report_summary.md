
Lab Report Summary

 Introduction
This project demonstrates the deployment of a lightweight honeypot detection environment using OpenCanary and Samba on Ubuntu Linux. The honeypot was configured to simulate exposed services (SSH, HTTP, SMB, MySQL) and capture attacker behavior through detection logs.

 Objectives
- Deploy a honeypot-based detection environment
- Simulate attacker behavior against exposed services
- Capture and analyze intrusion attempts
- Monitor suspicious SMB, SSH, and HTTP activity
- Map detections to MITRE ATT&CK techniques
- Demonstrate SOC monitoring workflows

 Conclusion
The lab successfully captured:
- SSH brute-force attempts
- HTTP reconnaissance activity
- SMB share enumeration and file retrieval

This project improved practical understanding of intrusion detection, attacker behavior, honeypot deployment, and SOC monitoring workflows. It reflects realistic analyst tasks such as monitoring, log analysis, and detection engineering.
